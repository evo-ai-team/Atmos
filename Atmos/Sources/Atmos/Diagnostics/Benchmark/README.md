# Live benchmarks

This removable `TESTING` feature is part of the regular Atmos app and defaults to off each launch. Settings enables a session, pauses the microphone, and uses the existing typed-command entry point. Prompts, model settings, screenshot mapping, and dispatch remain the ordinary application paths. For controlled comparisons, each trial starts with the command context saved when benchmark mode was enabled; after terminal cleanup, that original context is restored and any paused test goal is cleared. Test actions remain in the diagnostic action log but do not accumulate as model command context across trials.

`BenchmarkRecorder` retains the first and last existing observations without encoding or writing it during the measured trial. After the trace reaches a terminal state and cancelled input cleanup finishes, it writes `report.json`, `timing.txt`, `first-screen.jpg`, `first-ax.json`, `first-frame.json`, and matching `last-observed-*` artifacts into a unique `TESTING-<UUID>` directory under `~/Library/Application Support/Atmos/Benchmarks`. Reports include the command, routes, attempted actions, returned usage deltas, stage timings, distinct cutoff reasons, starting context count, and limitations. The last observed frame has its capture uptime and may precede later input or cancellation; it is not guaranteed to show the final screen. Screenshots, accessibility text, commands, and action payloads can contain private content; API authorization headers and raw request bodies are not logged. Visible or typed credentials can still appear in the screenshots, accessibility data, or action payloads. Earlier exports remain until the user removes them.

`BenchmarkSession` in AtmosCore enforces a 30-second trial deadline, six action batches per trial, and 30 request attempts per enabled session. Decisions and Responses fallback count separately. A batch may contain up to twelve individual actions. After six batches, the model can still declare completion, answer, or pause; a seventh action batch is rejected before dispatch. A 100 ms main-actor monitor provides cancellation even during initial selection; it is subject to main-actor scheduling and cannot undo already-dispatched input or provider work. Microphone entry and duplicate submissions are blocked during benchmark mode/trials. Disabling cancels any active trial, exports it, and restores the microphone's prior state.

Benchmark traces allow 2,048 stages and 512 metadata annotations; ordinary trace limits stay unchanged. Exported completion is Atmos's declaration, not independently verified success. Reported token usage can omit cancelled requests and the dollar figure is only an estimate.

Removal is localized: remove this directory, the two `Benchmark*` AtmosCore diagnostics files and their tests, the `TESTING` AppModel hooks and Settings section, and the benchmark-only optional timing capacities. Remove this README's package/project exclusions too. No startup mode or preference is persisted. The earlier experimental app is not needed.
