# Keychain storage

`KeychainStore` saves the OpenAI API key in macOS Keychain. Normal state refreshes use noninteractive reads; only the user's reconnect/save action may trigger authorization UI.

The historical Keychain service and app identifier are intentional compatibility values. Changing them can make an existing saved key inaccessible. Keep keys out of logs, fixtures, screenshots generated by diagnostics, and application preferences.
